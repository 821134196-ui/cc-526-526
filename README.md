# 业委会表决系统

业主大会电子表决演示系统：议题公示、资格名册冻结、投票版本管理、代理授权、
过户处理、计票复核与结果公布。纯 Python 标准库实现（`http.server` + `sqlite3`
+ `unittest`），零第三方依赖。

## 启动

```bash
python3 app.py            # 首次运行自动建库并灌入样例（含过户与代理）
python3 app.py --reset    # 清空数据并重新生成样例
python3 app.py --port 8080
```

打开 http://127.0.0.1:8000 ，在登录页选择身份（演示环境免密）：

| 身份 | 能做什么 |
|---|---|
| 王主任（业委会） | 发起/变更议题、登记过户、查看名册与通知记录 |
| 李计票（计票员） | 截止后执行计票 |
| 赵复核（复核员） | 复核并公布结果（与计票员不得为同一人） |
| 陈一…吴十（业主） | 投票、改票、撤票、委托代理、受托代投 |

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖需求点名的四类场景：
- `tests/test_roster_snapshot.py` — 资格快照：名册在议题发起时冻结，
  此后过户不影响本次资格，新业主提交记为无效票；新议题使用新名册。
- `tests/test_deadline.py` — 截止边界：有效期含端点；逾期提交记为无效票
  且留痕；逾期改票不覆盖原有效票；截止后禁撤票、禁计票。
- `tests/test_tally.py` — 票数与面积汇总：最新有效版本口径、同户多人提交、
  撤票、无效票原因、参与比例与通过判定。
- `tests/test_privacy.py` — 隐私权限：公布前管理人（业委会/计票员/复核员）
  不得查看个人选择，业主仅见本户；计票员与复核员不得为同一人。

## 样例数据（`--reset` 后）

- **议题#1 快递柜方案**：已公布结果，含 1 张逾期无效票、1 条撤票记录。
- **议题#2 电梯广告合同**：投票中。含代理授权（1-104 李四委托 1-101 陈一，
  授权书在 `data/proxy_docs/`）、过户样例（2-103 孙八 → 郑新，郑新提交被记
  无效票，名册业主孙八仍可有效投票）、同户多人提交（2-104 周九自投弃权后，
  受托人陈一代投赞成，计票只取最新有效版本）。
- **议题#3/#4 车库月租**：v1 已作废（内容变更），v2 重新发起——议题一经
  发布不可直接修改，变更即作废重发，全程留痕。

## 目录结构

```
app.py               入口：建库、灌样例、起服务
voting/
  db.py              SQLite schema（投票版本、名册快照、计票单等）
  services.py        领域服务：议题/投票/代理/过户/计票/公布/隐私
  web.py             HTTP 路由与服务端渲染页面
  seed.py            样例数据
  notify.py          模拟通知适配器（落库 + 控制台打印）
tests/               unittest 测试
data/                运行时生成：vote.db 与代理授权书文件
```

## 关键设计

- **名册快照**：议题发布时把当前权属关系冻结进 `roster_entries`，
  此后过户只影响新议题；资格核对页展示冻结名册。
- **投票版本**：同户每次提交追加一行 `votes`（`BEGIN IMMEDIATE` 串行化
  版本号），计票只取该户“最新的有效版本”（未撤回且无无效标记）；
  被取代版本、撤票、无效票全部留痕可追溯。
- **无效票落库**：逾期、非名册、代理失效的提交不静默丢弃，记
  `invalid_reason` 入库，公布页列出原因，支持截止时间争议追溯。
- **隐私**：公布前 `get_ballots` 对非名册业主一律拒绝；管理人在截止前
  只能看到参与计数（`participation_stats` 不含任何选择信息）。
- **计票复核分离**：计票员（teller）截止后计票，复核员（reviewer）复核
  公布；用户可兼任多角色，但同一人计票又复核会被服务层拦截。
- **计票规则**：发起时冻结（默认参与双三分之二、赞成双过半，民法典
  第二百七十八条口径），随议题版本保存。
- **界面**：白底、深灰正文、少量公示蓝。表决页同屏呈现议题原文、截止
  时间与当前选择；公布页并列展示户数比例与面积比例，并说明无效票原因。

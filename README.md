# 小区业主表决系统

业委会对公共区域使用、服务合同等事项发起表决的演示系统：议题公示、资格核对、
业主投票（含代理）、计票复核、结果公布全流程，全程可追溯。

**零依赖**：仅使用 Python 3 标准库（`http.server` + `sqlite3`），无需安装任何包。

## 启动

```sh
./start.sh            # 或：python3 app.py
# 首次运行自动建库并写入演示数据（含过户样例与代理样例）
# 打开 http://127.0.0.1:8000
```

常用参数：`--port 8080` 换端口；`--reset` 清空数据库重新生成演示数据。

## 运行测试

```sh
python3 -m unittest discover -s tests -v
```

覆盖：资格快照（冻结后过户不影响本次资格）、截止边界（截止前 1 秒可投、
到点即拒并留痕）、票数与面积汇总（双维度判定、无效票除外）、隐私权限
（截止前管理人也看不到个人选择）、并发提交只保留最新版本、
计票员与复核员不得为同一人、代理投票、议题公示后不可改。

## 规则实现对照

| 要求 | 实现 |
|---|---|
| 议题版本 | `topic_versions` 不可变版本链；公示后修改被拒绝，须重新发起 |
| 投票资格名册 | 投票开始时冻结快照（`rosters`/`roster_entries`），此后过户不影响 |
| 起止时间与截止争议 | 以服务器时间为准；被拒绝的投票尝试也写入审计日志 |
| 同户多人/并发提交 | 事务内作废旧版本 + 唯一部分索引，同户仅一条 active 票，全部版本留痕 |
| 撤票 | 截止前可撤回，状态 `withdrawn` 不计票 |
| 无效票 | 计票期间由计票员/监票人核定并必填原因，结果页公示 |
| 代理投票 | 授权书存本地 `data/auth_files/`，同户仅一条有效授权，可撤销 |
| 隐私 | 截止前任何人（含管理人）看不到个人选择；审计不记录选项 |
| 计票复核 | 计票员计票 → 复核员复核（不得同人）→ 监票人核对公布 |
| 通知 | 模拟适配器，全部写入本地出站记录（通知记录页） |

## 计票规则

默认按《民法典》第二百七十八条：参与户数与参与面积均达名册 2/3 为有效表决；
同意户数与同意面积均超参与半数方为通过。公示议题时可调整两个门槛参数。

```
  db.py           SQLite schema 与事务助手
  services.py     业务规则（议题/名册/投票/代理/过户/计票/公布/隐私）

  views.py        页面渲染（白底、深灰、公示蓝）
  seed.py         演示数据（含过户与代理样例）
  notify.py       模拟通知适配器
tests/test_voting.py
data/             运行期生成：vote.db、授权文件、会话密钥
```
